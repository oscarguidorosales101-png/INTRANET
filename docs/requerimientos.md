# Requerimientos

## Funcionales

- [x] Inicio de sesión simulado por rol.
- [x] Gestión y búsqueda de estudiantes.
- [x] Estados académico aprobados, aplazados y reprobados.
- [x] Visualización de cursos y docentes.
- [x] Calificaciones y asistencia académica.
- [x] Calendario académico.
- [x] Notificaciones y comunicados.
- [x] Navegación de retorno al panel administrativo.

## No funcionales

- [x] Diseño responsive y legible.
- [x] Consistencia visual entre vistas administrativas.
- [x] Rutas locales verificables y JavaScript sin dependencias de build.
- [x] Datos simulados centralizados para facilitar el mantenimiento.
- [x] Compatibilidad con navegadores modernos.
